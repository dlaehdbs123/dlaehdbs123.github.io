# GitHub Pages Website

A static personal website ready for GitHub Pages.

## Customize

- Edit `index.html` to replace the placeholder name, email, project descriptions, and links.
- Edit `styles.css` to adjust colors, layout, and image choices.
- Keep `.nojekyll` so GitHub Pages serves the site as plain static files.

## Publish

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Add these files to the repository.
3. Push to the `main` branch.
4. Open `https://YOUR-USERNAME.github.io`.
